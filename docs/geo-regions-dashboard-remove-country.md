# شيل اختيار الدولة من فورم المناطق الجغرافية

التعديل ده على فورم الإنشاء والتعديل فقط. الموبايل بقى بيستلم كل المناطق النشطة من غير ما يبص على دولة الحساب، فاختيار الدولة في الفورم مش له أثر على اللي يوصل للتطبيق.

الباك إند بقى يقبل `POST` و `PUT` من غير `country_id`. لو الحقل اتبعت هيتسجل، ولو ماتبعّتش المنطقة تتحفظ من غيره.

---

## المطلوب في الفورم

1. **شيل Select الدولة** من شاشة الإنشاء ومن شاشة التعديل.
2. **متبعتش `country_id`** في `POST /api/admin/geo-regions` ولا في `PUT /api/admin/geo-regions/{id}`.
3. متستناش اختيار دولة عشان تفتح الخريطة. في الإنشاء افتح الخريطة على view افتراضي (أو آخر مكان الأدمن وصله من البحث). في التعديل اعمل fit على `bounds` زي ما هو.
4. المناطق التانية على الخريطة (اللون الباهت): هاتها من غير فلتر دولة:

```
GET /api/admin/geo-regions?status=active&limit=100
```

5. قائمة الكوبون: اعرض الكوبونات النشطة من غير ما تفلترها على دولة المنطقة. خيار "بدون كوبون" يفضل موجود.

## مثال الطلب بعد التعديل

```json
POST /api/admin/geo-regions
{
  "name": { "ar": "العليا", "en": "Olaya" },
  "push_title": { "ar": "خصم 20% قريب منك", "en": "20% off near you" },
  "push_body": { "ar": "احجز جلستك النهارده بكود SUMMER20", "en": "Book today with code SUMMER20" },
  "points": [
    { "lat": 24.7136, "lng": 46.6753 },
    { "lat": 24.7136, "lng": 46.7386 },
    { "lat": 24.7743, "lng": 46.7386 },
    { "lat": 24.7743, "lng": 46.6753 }
  ],
  "priority": 10,
  "market_coupon_id": null,
  "is_active": true,
  "expires_at": null
}
```

## اللي يفضل زي ما هو

- الاسم، عنوان الإشعار، نص الإشعار، النقاط الأربعة، الأولوية، الكوبون، التفعيل، وتاريخ الانتهاء.
- فحص المضلع (4 نقاط، من غير تقاطع، ومساحة 2,500 م² على الأقل).
- عمود الدولة في الجدول وفلتر `country_id` في القائمة اختياريين للعرض. المناطق القديمة لسه راجعة وفيها `country`. المناطق الجديدة من غير دولة راجعة بـ `country_id: null` و `country: null`.
